MVC map

Where each piece of code lives: where we are now, and where we're going.

Heads-up: this is the "textbook" picture. Most MVC diagrams online are drawn for servers, where the user's request goes straight to the controller. In BoardingEase everything runs in the browser, so the student's typing or click lands on a View first. The view calls handler(value), and that's how the request reaches the controller. Every interaction follows the same 4 steps

  1. UserTypes, clicks, or ticks something on the page.
  2. View → ControllerThe view's listener calls the controller it was given in init().
  3. Controller → ModelThe controller asks the model to update state.
  4. Controller → ViewThe controller passes the new state to view.render().

The 3 rules

  • Model never touches the DOM (no document, no HTML).
  • View never imports the model. It only gets data passed into render(data).
  • Controller (app.js) imports both and connects them. It's the only file that knows about everyone.
