01Start here

BoardingEase helps DOrSU students find boarding houses near campus: search by name or barangay, filter by rent, then split the monthly cost with housemates.

How to run it

  1. Open the project folder in VS Code.
  2. Right-click index.html → Open with Live Server.
  3. Open DevTools (F12 or Cmd+Option+I) and keep the Console tab visible while you work.

⚠ Double-clicking index.html won't work. The page loads app.js as a module (index.html:83), and browsers block modules on file:// pages. You'll see a CORS error in the console. Always use Live Server.

How to read this guide

  • Grey chips like model.js:10 are file:line locations. Click one to jump to that exact line in the full source.
  • Blue function() links jump to that function's card in the reference. Every card lists who calls it and what it calls.
  • Badges show the MVC layer: Model View Controller.
  • Stuck on "where does this value come from?" Go to Follow the data, which walks through real clicks and keystrokes step by step.

Which app.js? This guide explains the week-5 version of the controller, which is now saved as js/app(old).js. The new js/app.js is the Lab 3 skeleton (defense on Monday, October 5), and index.html loads that one, so the page stays blank until you finish the lab. When this guide says "app.js", it means the code in app(old).js.

MVC in one paragraph

The code is split into three jobs. The Model (data.js, model.js) holds the data and the rules for filtering it, and never touches the page. The View files (views/) read what the user types and draw HTML, and they never import the model. The Controller (app.js) connects the two: when a view reports that something happened, a controller asks the model to update, then tells the view to re-draw. The MVC diagram shows this as a picture.

10Self-check

1. What happens when resultsView.render([]) is called?

The guard in render sees an empty array View.js:9 and returns this.renderError(). With no argument, the message defaults to this._errorMessage, so the list shows the "No listings match…" box. _generateMarkup never runs.

2. Who calls applyFilters()? Does app.js ever call it?

Only setSearchTerm model.js:29 and setMaxRent model.js:34, both inside model.js. app.js never calls it directly: it only says "the search term changed", and the model decides to re-filter.

3. searchController is defined in app.js. On which line does it actually get called?

Inside SearchView: handler(e.target.value) SearchView.js:9. app.js only passes it over at app(old).js:181, without parentheses.

4. Why is View exported as a class, but SearchView as new SearchView()?

Other classes need to extends View, and you can't extend an object. Nobody uses a plain View anyway, because it has no _parentElement. SearchView is just used, and there's only one search form, so everyone should share one object. If each file did new SearchView(), you'd get duplicate listeners.

5. state.maxRent holds "5000", a string. Why, and what does "" mean?

Input values are always strings. "" means the box is empty, which the app treats as "no limit" model.js:21. The conversion to a number happens only at the comparison, with Number(maxRent).

6. You click the image inside a card. How does the code still get the right id?

event.target is the <img>. .closest(".card") climbs to the <button class="card"> around it app(old).js:144, and .dataset.id reads its data-id app(old).js:148.

7. Why does selectedListing() search state.listings instead of state.filtered?

If you select a card and then search for something else, that listing is no longer in filtered. Searching filtered would return undefined, and the breakdown would stop updating. Looking something up by id should search everything.

8. What would you see if _generateMarkup forgot its return?

markup would be undefined, and insertAdjacentHTML turns that into the text "undefined" on the page, with no error in the console.

9. Casa Amihan, 4 people, fare ticked: what's the per-person total, and why?

6500 ÷ 4 = 1625 rent, plus 2950 ÷ 4 = 737.5 utilities, plus 15 × 2 × 22 = 660 fare, gives 3022.5, which peso.format rounds to ₱3,023. The fare isn't divided, because everyone rides separately.

data.js and model.js, the Model. That's rule #1 of MVC.
